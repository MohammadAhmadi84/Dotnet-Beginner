# 🎯 MyDotNetApp

Welcome to **MyDotNetApp** – a beginner-friendly .NET application designed to help you get started with C# and the .NET ecosystem.

This project demonstrates the basics of building a .NET console/web application, including project structure, dependencies, and basic functionality.

---

## 🧰 Tech Stack

- [.NET 8.0](https://dotnet.microsoft.com/)
- C#
- ASP.NET Core if it's a web app
- Entity Framework Core

---

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [.NET SDK](https://dotnet.microsoft.com/en-us/download) (8.0)
- [JetBrains Rider](https://www.jetbrains.com/rider/) – recommended IDE for this project
- Git (for version control)
